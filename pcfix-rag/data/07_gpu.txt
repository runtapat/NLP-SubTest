# ปัญหาการ์ดจอ (GPU Problems)

อาการการ์ดจอมีปัญหา: ภาพแตก มีเส้นหรือจุดสีแปลกๆ บนหน้าจอ (Artifacting) ภาพกระพริบ จอดำชั่วขณะแล้วกลับมา เกมกระตุกหรือค้าง พัดลมการ์ดจอหมุนเต็มที่ตลอดเวลา หรือ Windows แจ้งว่า "Display driver stopped responding and has recovered"

สาเหตุที่พบบ่อย: ไดรเวอร์เก่าหรือเสียหาย อุณหภูมิสูงเกินไป การ์ดจอเสียบไม่แน่น สาย PCIe Power ไม่ครบ PSU จ่ายไฟไม่พอ โอเวอร์คล็อกมากเกินไป หรือหน่วยความจำ VRAM เสื่อม

วิธีแก้ไข:
1. ติดตั้งไดรเวอร์ใหม่โดยใช้ DDU (Display Driver Uninstaller) ถอนไดรเวอร์เก่าในโหมด Safe Mode ก่อน แล้วดาวน์โหลดไดรเวอร์ล่าสุดจากเว็บไซต์ NVIDIA, AMD หรือ Intel
2. ตรวจสอบอุณหภูมิด้วย MSI Afterburner หรือ HWiNFO อุณหภูมิ GPU ขณะเล่นเกมไม่ควรเกิน 85°C
3. ถอดการ์ดจอมาทำความสะอาดฝุ่น และเสียบกลับให้แน่นในช่อง PCIe x16 ช่องแรก
4. ตรวจสอบสาย PCIe Power (6-pin, 8-pin หรือ 12VHPWR) ให้เสียบครบและแน่น ไม่ควรใช้ตัวแยกสายที่ไม่ได้คุณภาพ
5. ปิดการโอเวอร์คล็อกและคืนค่าเริ่มต้น
6. ทดสอบด้วย FurMark หรือ 3DMark ถ้าเห็น artifact ซ้ำในโปรแกรมทดสอบ แสดงว่าฮาร์ดแวร์น่าจะเสีย

การ์ดจอแยกกับกราฟิกในตัว: ถ้าเครื่องมีทั้งสองแบบ เกมอาจรันด้วยกราฟิกในตัวทำให้ช้า ตรวจสอบใน Windows Settings > Graphics เพื่อเลือกให้ใช้การ์ดจอแยก

ปัญหา Bottleneck: ถ้าใช้ CPU เก่าเกินไปจับคู่กับการ์ดจอรุ่นใหม่ CPU จะทำงานเต็มที่จนการ์ดจอทำงานไม่เต็มประสิทธิภาพ

การรับประกัน: การ์ดจอส่วนใหญ่มีรับประกัน 3 ปี ควรเก็บใบเสร็จและกล่องไว้ ห้ามแกะสติกเกอร์รับประกันบนตัวการ์ด มิฉะนั้นอาจเสียสิทธิ์

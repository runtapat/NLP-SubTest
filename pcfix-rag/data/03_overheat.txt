# เครื่องร้อนจัดและพัดลมดัง (Overheating & Fan Noise)

อาการ: เครื่องช้าลง กระตุก ค้าง ดับเอง หรือพัดลมหมุนเสียงดังตลอดเวลา

อุณหภูมิที่เหมาะสม: CPU ขณะใช้งานปกติควรอยู่ที่ประมาณ 30-50 องศาเซลเซียส (°C) ขณะโหลดหนัก เช่น เล่นเกม ไม่ควรเกิน 80-85°C หากสูงกว่า 90°C ถือว่าอันตราย เครื่องจะลดความเร็วอัตโนมัติ (Thermal Throttling) และอาจดับเองเพื่อป้องกันความเสียหาย

เครื่องมือตรวจสอบ: ใช้โปรแกรม HWMonitor, Core Temp, MSI Afterburner หรือ HWiNFO ดูอุณหภูมิ CPU และ GPU

สาเหตุที่พบบ่อย: ฝุ่นอุดตันในฮีตซิงก์และพัดลม ครีมซิลิโคน (Thermal Paste) แห้งเมื่อใช้งานนาน 2-3 ปี การระบายอากาศของเคสไม่ดี พัดลมเสียหรือแบริ่งสึก วางโน้ตบุ๊กบนเตียงหรือผ้านุ่มที่อุดช่องระบายอากาศ

วิธีแก้ไข:
1. ปิดเครื่อง ถอดปลั๊ก ใช้ลมเป่าฝุ่นออกจากฮีตซิงก์ พัดลม และช่องระบายอากาศ ควรจับใบพัดไว้ไม่ให้หมุนขณะเป่า เพราะอาจทำให้แบริ่งเสียหาย
2. เปลี่ยนครีมซิลิโคนใหม่ โดยเช็ดของเก่าด้วยแอลกอฮอล์ไอโซโพรพิล (IPA) 90% ขึ้นไป แล้วทาใหม่ขนาดเมล็ดถั่วเขียวตรงกลาง CPU
3. จัดระบบลมในเคส โดยพัดลมหน้าดูดลมเย็นเข้า พัดลมหลังและด้านบนดูดลมร้อนออก
4. สำหรับโน้ตบุ๊ก ใช้ฐานรองระบายความร้อน (Cooling Pad) และวางบนพื้นผิวแข็ง
5. ตั้งโหมดพลังงานเป็น Balanced และตรวจสอบโปรแกรมที่กิน CPU สูงผิดปกติใน Task Manager

เสียงพัดลมดังผิดปกติ: ถ้ามีเสียงครืดคราดหรือเสียงหวีด มักเกิดจากแบริ่งพัดลมเสื่อม ควรเปลี่ยนพัดลมใหม่ ถ้าเสียงดังเฉพาะตอนบูตแล้วเบาลง ถือเป็นเรื่องปกติ

ควรทำความสะอาดทุก 6-12 เดือน หรือทุก 3-6 เดือนหากมีฝุ่นมากหรือมีสัตว์เลี้ยง

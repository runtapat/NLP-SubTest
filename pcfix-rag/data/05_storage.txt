# ปัญหาฮาร์ดดิสก์และ SSD (Storage Problems)

อาการฮาร์ดดิสก์ (HDD) มีปัญหา: เปิดเครื่องช้ามาก ไฟล์เปิดไม่ได้หรือเสียหาย เครื่องค้างเป็นช่วงๆ มีเสียงคลิก (Click of Death) หรือเสียงขูดจากตัวดิสก์ แจ้งเตือน "Disk Boot Failure" หรือไม่พบอุปกรณ์บูต

คำเตือนสำคัญ: หากได้ยินเสียงคลิกหรือเสียงขูดจากฮาร์ดดิสก์ ให้ปิดเครื่องและสำรองข้อมูลทันที การใช้งานต่อจะทำให้ข้อมูลเสียหายมากขึ้น

การตรวจสอบสุขภาพดิสก์: ใช้โปรแกรม CrystalDiskInfo อ่านค่า S.M.A.R.T. ถ้าสถานะเป็น "Caution" หรือ "Bad" ควรเปลี่ยนไดรฟ์ ค่าที่ต้องระวังคือ Reallocated Sectors Count, Current Pending Sector และ Uncorrectable Sector Count หากมีค่ามากกว่า 0 และเพิ่มขึ้นเรื่อยๆ แสดงว่าดิสก์กำลังเสื่อม

คำสั่งใน Windows: เปิด Command Prompt แบบ Administrator แล้วพิมพ์ chkdsk C: /f /r เพื่อตรวจสอบและซ่อมแซม bad sector ทางตรรกะ ใช้เวลานานและต้องรีสตาร์ทเครื่อง

อาการของ SSD: ไม่มีเสียงเหมือน HDD แต่เมื่อเสียมักหายไปจาก BIOS ทันที หรือเข้าสู่โหมดอ่านอย่างเดียว (Read-only) ดูอายุการใช้งานจาก Percentage Used หรือ Health ใน CrystalDiskInfo ถ้าเหลือต่ำกว่า 10% ควรเตรียมเปลี่ยน

ปัญหาไม่พบดิสก์ในเครื่อง: ตรวจสอบสาย SATA และสายไฟ SATA ลองสลับพอร์ต SATA บนเมนบอร์ด สำหรับ NVMe ให้ถอดและเสียบใหม่ในช่อง M.2 และตรวจสอบว่าเมนบอร์ดรองรับชนิด NVMe หรือ SATA ตรงกับ SSD

ข้อควรปฏิบัติ: ควรเหลือพื้นที่ว่างใน SSD อย่างน้อย 10-20% ไม่ควรดีแฟรกเมนต์ SSD (ใช้ TRIM แทน) ควรสำรองข้อมูลตามหลัก 3-2-1 คือสำเนา 3 ชุด บนสื่อ 2 ประเภท และเก็บไว้นอกสถานที่ 1 ชุด

การกู้ข้อมูล: ถ้าดิสก์ยังตรวจพบ ใช้ Recuva หรือ TestDisk แต่ถ้าเสียหายทางกายภาพควรส่งศูนย์กู้ข้อมูล ซึ่งมีค่าใช้จ่ายสูง

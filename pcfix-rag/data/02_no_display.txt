# เปิดเครื่องติดแต่จอไม่ขึ้นภาพ และรหัสเสียงบี๊ป (No Display / Beep Codes)

อาการ: พัดลมหมุน ไฟติด แต่หน้าจอดำ ไม่มีสัญญาณ (No Signal)

สาเหตุที่พบบ่อย: สายสัญญาณภาพ (HDMI/DisplayPort) หลวม เสียบผิดช่อง RAM ไม่แน่น การ์ดจอมีปัญหา หน้าจอเสีย หรือ BIOS ผิดพลาด

ข้อผิดพลาดยอดนิยม: เสียบสายจอเข้าช่องของเมนบอร์ดทั้งที่ติดตั้งการ์ดจอแยก (Dedicated GPU) ต้องเสียบสายจอที่ช่องของการ์ดจอเท่านั้น

ขั้นตอนแก้ไข:
1. ตรวจสอบสายสัญญาณภาพ ลองสลับสายหรือเปลี่ยนพอร์ต เช่น จาก HDMI เป็น DisplayPort
2. ถอด RAM ออก เช็ดขาทอง (gold contacts) เบาๆ ด้วยยางลบดินสอ แล้วเสียบใหม่ให้แน่นจนได้ยินเสียงคลิก
3. ถอดการ์ดจอแล้วเสียบใหม่ ตรวจสาย PCIe Power ว่าเสียบครบ
4. ล้างค่า CMOS โดยถอดแบตเตอรี่กระดุม CR2032 บนเมนบอร์ดประมาณ 1-5 นาที แล้วใส่กลับ หรือใช้จัมเปอร์ CLR_CMOS
5. ทดสอบหน้าจอกับอุปกรณ์อื่น เพื่อแยกว่าจอเสียหรือเครื่องมีปัญหา

เสียงบี๊ปจาก BIOS (POST Beep Codes): สำหรับ AMI BIOS บี๊ปสั้น 1 ครั้ง หมายถึงผ่านการตรวจสอบปกติ บี๊ปสั้น 3 ครั้งติดกัน มักหมายถึงปัญหา RAM บี๊ปยาว 1 ครั้ง สั้น 2 ครั้ง มักหมายถึงปัญหาการ์ดจอ สำหรับ Award BIOS บี๊ปยาวซ้ำๆ มักหมายถึงปัญหา RAM ความหมายต่างกันตามผู้ผลิต ควรตรวจสอบจากคู่มือเมนบอร์ดรุ่นนั้น

เมนบอร์ดบางรุ่นมีหลอด LED Debug หรือจอแสดงรหัส Q-Code บอกจุดที่เครื่องค้าง เช่น CPU, DRAM, VGA, BOOT ให้ดูไฟที่ติดค้างเพื่อระบุอุปกรณ์ที่มีปัญหา

หมายเหตุ: ถ้า CPU มีกราฟิกในตัว สามารถถอดการ์ดจอแล้วเสียบสายจอที่เมนบอร์ดเพื่อทดสอบว่าการ์ดจอเสียหรือไม่

# ปัญหาหน่วยความจำ RAM

อาการที่บ่งชี้ว่า RAM มีปัญหา: เครื่องรีสตาร์ทเอง จอฟ้า (BSOD) บ่อย โปรแกรมค้างหรือปิดเอง ไฟล์เสียหาย เปิดเครื่องไม่ผ่าน POST และมีเสียงบี๊ปซ้ำๆ หรือ Windows แสดงปริมาณ RAM น้อยกว่าที่ติดตั้ง

การตรวจสอบ RAM:
1. ใช้ Windows Memory Diagnostic โดยพิมพ์ชื่อในช่อง Search แล้วเลือก Restart now and check for problems
2. ใช้ MemTest86 (บูตจาก USB) รันอย่างน้อย 4 รอบ (4 passes) หากพบ error แม้เพียง 1 ครั้ง แสดงว่า RAM มีปัญหา
3. ทดสอบทีละแถว โดยเสียบ RAM ทีละแถวในช่องเดียวกัน เพื่อระบุแถวที่เสีย

การแก้ไข:
- ถอดและเสียบ RAM ใหม่ให้แน่น เช็ดขาทองด้วยยางลบ
- ลองเสียบช่องอื่น เพื่อตรวจสอบว่าช่อง RAM บนเมนบอร์ดเสียหรือไม่
- ตรวจสอบว่าใช้ RAM ชนิดที่เมนบอร์ดรองรับ DDR3, DDR4 และ DDR5 ใช้แทนกันไม่ได้เพราะรอยบากไม่ตรงกัน
- เปิด XMP/EXPO ใน BIOS เพื่อให้ RAM ทำงานที่ความเร็วที่โฆษณา แต่ถ้าเครื่องไม่เสถียรให้ปิด XMP
- อัปเดต BIOS หากเมนบอร์ดมีปัญหากับ RAM บางรุ่น

Dual Channel: หากมี 2 แถว ควรเสียบในช่องที่คู่มือระบุ (มักเป็นช่อง A2 และ B2) เพื่อประสิทธิภาพสูงสุด

กรณี Windows แสดง RAM น้อยกว่าติดตั้ง: ตรวจสอบว่าใช้ Windows 32-bit ซึ่งรองรับ RAM ประมาณ 4 GB เท่านั้น ให้เปลี่ยนเป็น 64-bit และตรวจสอบค่า Hardware Reserved ใน Task Manager

ปริมาณ RAM ที่แนะนำ: งานทั่วไปและเรียนออนไลน์ 8 GB เล่นเกมทั่วไป 16 GB ตัดต่อวิดีโอหรือทำงาน 3 มิติ 32 GB ขึ้นไป
